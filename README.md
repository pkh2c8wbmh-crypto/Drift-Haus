# Drift Haus Creative Studio

This is the exact static website and assets from the published Sites version, packaged as a runnable Node web service for GitHub repository import into Base44. It has no database or private backend.

## Local preview

Run `npm start`, then open `http://localhost:3000`. Set `PORT` to change the listening port.

## Base44

Put the contents of this folder at the root of a GitHub repository. From the Base44 home page, select `+` in the new project prompt, then `Connect your repo`, authorize GitHub, choose this repository, and connect. This creates a new Base44 project; it does not replace an existing Base44 app.

All image assets are in `assets/`. The primary page is `index.html`.
